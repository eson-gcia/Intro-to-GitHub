# Git Notes

## Common Git Commands

- `git clone` - Copies a remote repository to the local computer.
- `git status` - Displays the current state of the working directory.
- `git add` - Stages changes for a commit.
- `git commit` - Saves staged changes to the Git history.
- `git push` - Uploads local commits to GitHub.
- `git pull` - Retrieves changes from GitHub.
- `git branch` - Displays or manages branches.
- `git merge` - Combines changes from different branches.
