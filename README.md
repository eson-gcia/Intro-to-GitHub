# Intro-to-GitHub

## Description

This repository was created as part of an introductory activity on Git and GitHub. It demonstrates the basic concepts and workflow of version control, including repositories, commits, branches, cloning, pushing, and managing files using Git and GitHub.

## Objectives

* Understand the purpose of Git and GitHub.
* Learn the basic concepts of version control.
* Practice creating and managing a GitHub repository.
* Use Git commands to clone, modify, commit, and push files.
* Understand the relationship between a local Git repository and a remote GitHub repository.

## Contents

* `README.md` — Description and documentation of the repository.
* `hello.py` — A simple Python program demonstrating a Git-managed file.
* `git-notes.md` — Notes about basic Git concepts and commands.
* `sample.txt` — A sample text file used to demonstrate file management.

## Technologies

* Git
* GitHub
* Python
* Visual Studio Code
